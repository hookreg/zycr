Dataset 决定一条数据是什么。

DataLoader 决定这些数据如何被组合， 并送入模型。

[ 03 // NOTES ]

3. 一个容易混淆的问题

DataLoader 并不是用来保存数据的。 它只是负责按照指定策略从 Dataset 中取出数据。

注意： 如果你的数据读取速度很慢， 不一定是 GPU 的问题， 也可能是数据加载过程成为了瓶颈。

[ 05 // MATHEMATICS ]

5. 数学表示

5.1 行内公式

假设一个 mini-batch 包含 $B$ 个样本， 每个样本的特征维度为 $d$。

那么输入矩阵可以表示为 $\mathbf{X}\in\mathbb{R}^{B\times d}$。

5.2 独立公式

一个简单的线性变换可以写成：

$$ \mathbf{H} = \mathbf{X} \mathbf{W} + \mathbf{b} $$

5.3 损失函数

例如均方误差：

$$ \mathcal{L} = \frac{1}{N} \sum_{i=1}^{N} \left( y_i-\hat{y}_i \right)^2 $$

5.4 多行公式

$$ \begin{aligned} \mathbf{q} &= \mathbf{W}_q\mathbf{x}, \\ \mathbf{k} &= \mathbf{W}_k\mathbf{x}, \\ \mathbf{v} &= \mathbf{W}_v\mathbf{x}. \end{aligned} $$

5.4.1 Attention 示例

$$ \operatorname{Attention} (\mathbf{Q},\mathbf{K},\mathbf{V}) = \operatorname{softmax} \left( \frac{ \mathbf{Q}\mathbf{K}^{\top} }{ \sqrt{d_k} } \right) \mathbf{V} $$
[ 06 // PYTHON ]

6. Python 示例

一个最简单的 DataLoader： 

import torch

from torch.utils.data import (
    Dataset,
    DataLoader
)


class MyDataset(Dataset):

    def __init__(self):
        self.data = torch.randn(100, 512)


    def __len__(self):
        return len(self.data)


    def __getitem__(self, index):
        return self.data[index]


dataset = MyDataset()


loader = DataLoader(
    dataset,
    batch_size=32,
    shuffle=True
)


for batch in loader:

    print(batch.shape)
